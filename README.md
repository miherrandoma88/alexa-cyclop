# Cíclope para Alexa

Experiencia conversacional de ciencia ficción con Cíclope y el módulo premium Quásar.

## Empezar

Di **«Alexa, abre protocolo cíclope»** y habla con naturalidad. Las respuestas generadas pueden contener errores.

## Órdenes útiles

| Frase | Resultado |
| --- | --- |
| Repite lo último | Repite la última respuesta conversacional correcta de esta sesión, sin generar otra. |
| Olvida esta conversación | Reinicia el diálogo actual; conserva recuerdos guardados y preferencias. |
| Recuerda que mi color favorito es turquesa | Guarda solo esa nota para otras sesiones. |
| Lee mis recuerdos | Consulta las notas guardadas. |
| Lee el recuerdo uno | Lee una nota completa. |
| Borra el recuerdo uno | Elimina esa nota y limpia el contexto actual. |
| Borra mis recuerdos | Elimina todas las notas guardadas y limpia el contexto actual. |
| Vuelve al modo normal | Desactiva la paranoia ficticia sin cambiar tus otros ajustes. |
| Ayuda | Explica las órdenes disponibles. |

La memoria es opcional: hasta **ocho notas de 180 caracteres**. No se guarda automáticamente toda la conversación. No guardes contraseñas ni claves. Consulta la [política de privacidad](privacy-policy.html) para distinguir recuerdos, contexto de sesión y otros datos de estado.

## Personajes y contenido premium

«Habla con Quásar» cambia al módulo premium cuando tienes acceso a Protocolo Pro. Con Quásar puedes ajustar los diales, por ejemplo «pon el humor al veintiuno» o «sinceridad al ochenta». Las compras y reembolsos se tramitan mediante Amazon.

## Reconocimiento de frases

La versión publicada reconoce las órdenes canónicas de la tabla. Las nuevas variantes naturales se validan en la copia de desarrollo antes de su publicación. No se debe interpretar un fragmento ambiguo como «mí» como una orden de consulta o borrado.
